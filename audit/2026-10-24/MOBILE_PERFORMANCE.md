# 手机端性能优化与损失评估（2026-10-24）

## 实现范围

- 中文汉字及中文标点使用系统字体；英文、阿拉伯数字及英文标点保留原有 MiSans Latin。正文和标题不再请求完整中文 MiSans，原始字体文件保留以兼容旧链接。代码、公式保留原有专用字体。
- 手机头图和文章列表封面增加 AVIF 备选，WebP 仍以原有质量 82 作为回退。构建时逐个响应式尺寸比较文件大小：AVIF 任一档位不小于 WebP，就保留原来的 WebP。
- 列表封面在进入视口上下 350px 范围时加载。用 template 避免浏览器提前请求远处封面，noscript 保留禁用 JavaScript 的图片；不支持 IntersectionObserver 时立即加载。
- 导航栏的搜索、显示设置、壁纸切换和手机菜单使用本地 SVG 数据及 Iconify 离线组件。只把当前需要的图标传给页面，不向浏览器发送整套图标库。Skills 页已有的专用图标加载器不在本次常用导航图标优化范围内。
- 波浪、粒子、打字机及其他动效的配置、数量和实现均未修改。

## 本地性能对照

修改前保存现有 dist，修改后正常构建。使用同一台机器的 Chromium、390×844 视口、DPR 1.75、4 倍 CPU 降速、150ms 网络延迟、200,000 bytes/s 下载限速，关闭浏览器缓存。

以下各为一次冷启动、页面 load 后再观察 1.5 秒、未滚动时的结果；流量是本机站点已完成请求的编码传输大小，包含响应头。为避免污染真实访问统计，测试中统计脚本统一返回 204。结果用于本地 A/B 排查，不等于线上 PageSpeed 的模拟分数或真实访客分布。

| 指标 | 修改前 | 仅替换中文字体的对照 | 最终版本 |
| --- | ---: | ---: | ---: |
| 首次加载流量 | 5,755,018 bytes（5.49 MiB） | 965,299 bytes | 733,767 bytes（0.70 MiB） |
| 字体请求 | 5,013,646 bytes | 130,836 bytes | 130,836 bytes |
| LCP | 4.596s | 3.728s | 3.176s |
| CLS | 0.00269 | 0.02120 | 0.02111 |
| 已激活的延后封面 | 不适用 | 不适用 | 2 / 7 |

最终版本在该场景中的首次加载流量减少约 87.2%。滚动后其余封面仍会加载，这个百分比不是整页全部资源的压缩比例。字体单项对照说明大部分流量下降来自移除完整中文字体，也出现了字体回退相关的少量布局移动；没有把原 PageSpeed 报告的 27.6s 全部归因于字体。

## 图片画质与体积

手机头图保持相同的 780×1063 像素、原有内容、裁切和显示尺寸：224,892 → 167,599 bytes，约减少 25.5%。390px 的图片档位也保留，未通过降低高清屏的分辨率来节省体积。

对实际构建产物及代表性封面进行了肉眼比较，并用同一原图缩放参考计算 8×8 亮度 SSIM 和 RGB PSNR。抽检的头图、数学黑板封面、人物封面及 FLAC 封面，两项指标均不低于原 WebP；这些指标只是辅助检查，不能证明所有细节无损。具体数值见 [image-quality.json](image-quality.json)，头图见 [对比图](mobile-banner-comparison.png)。

## 实际损失与取舍

1. **中文外观会改变。** 系统字体随 Windows、Android、iOS 不同，汉字字形、字重和换行可能不同。英文、数字和英文标点的 MiSans 字形保持原样。英文 Webfont 下载前仍可能短暂使用回退字体。本地 CLS 由约 0.003 增至约 0.021，并非完全没有布局移动。
2. **图片仍是有损编码。** 本次对比未发现明显细节损失，极细纹理和颜色仍可能有像素级变化；旧浏览器继续使用原质量的 WebP。
3. **快速滑动时封面可能晚出现。** 提前 350px 开始加载，可兼顾加载速度与首屏带宽，但极弱网、快速跨屏滚动时仍可能看到短暂空白。
4. **构建稍复杂。** 需要生成额外 AVIF 和比较大小。为了保留无 JavaScript 图片回退及内联图标数据，首页 HTML gzip 体积从 21,007 增至 23,115 bytes，约增加 2.1 KiB；这已经包含在上面的传输实测中。

## 验证结果

- Astro 检查：0 errors、0 warnings（18 个现有提示）。
- 54 项单元测试通过，含响应式 AVIF 选择与无 JavaScript 回退的构建测试。
- 正常构建 25 页，Pagefind 索引 16 页；既有静态产物、搜索、内容安全和个人设置校验通过。
- 浏览器实测搜索 FLAC、手机菜单、显示设置及 Escape 关闭面板正常；所有封面在滚动后加载成功。
- 390 / 768 / 1440px 的首页、文章页、About 页均无横向溢出。
- 浏览器读取实际渲染字体：英文/数字/英文标点为 MiSans Latin Regular，粗体为 MiSans Latin Semibold；中文为系统 Microsoft YaHei UI（本机 Windows）。
- 字体字符表检查：两个 Latin 字重均覆盖全部可打印 ASCII 字符、英文弯引号、破折号、省略号；不包含中文标点。
- 最终导航无 Iconify 外部接口请求；浏览器页面脚本错误为 0。
- 禁用 JavaScript、缺少 IntersectionObserver、使用 WebP 回退的路径均通过。
- 波浪仍为四层，首页粒子画布保留；动效相关源文件和配置无变更。
